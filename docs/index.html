Universal capture & personal knowledge archive for Android.

Eliminate digital fragmentation. Cobalt is your private vault for notes, media, audio memos, and links—featuring the 60/120fps SideDock, Gemini AI OCR region marking, and zero-telemetry local storage.

Engineered for focus and privacy

Everything you capture stays on your device. No user accounts, no cloud sync lock-in.

⚡

Cobalt SideDock

Summon instant capture from any app with a gentle screen-edge swipe. Renders at 60/90/120fps on the GPU RenderThread with 0% CPU footprint when resting.

🔍

Gemini AI OCR & Region Marking

Select any rectangle on your screen to extract text, code, or links directly over running apps. Uses your own Gemini API key with zero image storage on remote servers.

📝

Markdown & Continuous Editor

Write notes with standard Markdown syntax, real-time preview, code syntax highlighting, and fast search. Saved as private files in local storage.

🎙️

Voice Memos & Audio

Record quick audio clips with live waveform visualization. Optional Gemini transcription converts spoken thoughts to clean, formatted Markdown notes.

🎬

Media Hub & Trakt Sync

Search movies, TV shows, and anime via TMDb and Jikan. Connect Trakt using secure PKCE authorization to sync watch history, ratings, and watchlists.

🛡️

Zero-Telemetry Privacy

No analytics SDKs, no tracking pixels, and no automatic crash uploads. Optional third-party API keys and OAuth tokens are protected via Android Keystore (AES-GCM).
