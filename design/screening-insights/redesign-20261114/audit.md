# Your taste redesign · 14 November 2026

Scope: the native Screening transparency flow, using the user's three current screenshots and freshly captured Cobalt references.

1. **Why this pick — needs redesign.** The title, source, reason, runtime warning, calculation notes and publication history share the same small text treatment. Give the title a media card, show concise reasons, and put numerical/history details behind deliberate disclosures.
2. **Saved-title search — needs redesign.** A generic outlined field and identical text rows do not match Cobalt's search/picker patterns. Use its filled rounded search field, media thumbnails, clear availability labels, filters and useful empty states.
3. **Your feedback — needs redesign.** Each item repeats several metadata lines and multiple actions. Cleared feedback appears beside active evidence. Default to active feedback, use compact grouped rows, and open evidence/correction details on tap.

Reference: the freshly captured Pocket Folio settings screen uses a clear preview, short section headings, connected surfaces, consistent inset spacing and one primary action. The existing SearchScreen supplies the rounded search input and filter pattern. Figma's approved Screening/settings library supplies typography, colors, icons, buttons and navigation rows.

Accessibility: preserve 48 dp action targets, wrapping body text and explicit signed preference labels. Verify narrow screens and enlarged text after implementation. Screenshots alone do not establish screen-reader or full accessibility compliance.
