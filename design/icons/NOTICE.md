# Material icon attribution

The 29 SVGs under `svg/material-fallbacks/` are exported from AndroidX Compose Material icon source code, copyright The Android Open Source Project. They are licensed under the Apache License, Version 2.0; see `LICENSE-MATERIAL.txt`.

The conversion preserves the source path geometry and replaces its tint with neutral ink. Source package, version, Kotlin file and app usage are recorded for each icon in `manifest.json`. Auto-mirrored icons show their LTR geometry and can be mirrored horizontally for RTL layouts.

Other assets retain the licensing and ownership of their original Cobalt resources and third-party brand artwork.
