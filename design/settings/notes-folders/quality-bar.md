# Notes & folders quality bar

Extend the approved Cobalt Android Settings surface. Make the two existing preferences clear and useful: folder suggestions affect folder order; Archive view changes the summary at the top of Settings.

The folder example must carry real Cobalt folder identities. Work uses the work icon and Royal Indigo, Ideas the idea icon and Soft Gold, and Reading the app’s book/reading icon option and Emerald Sage. Label the panel Example and keep it independent of saved user data. The colors and icons stay associated with their folders when suggestions are turned off.

Use the existing compact grouped rows, Material theme and typography roles, serif collapsing header, tick/cross switch, and native Settings sheet. Explain ranking without promising a specific result: saved-item count, capture dates, content and type matching, pinned folders first, and alphabetical order for unpinned folders when suggestions are off.

Both choices must persist and affect the Settings archive. The controls and explanation must remain reachable on compact screens, with larger text, and in landscape. Back cancellation returns to the same state; Back completion dismisses a sheet or returns to Settings.

Native screenshots establish the build. Figma is a critique reference using the approved library’s theme roles; the installed app follows wallpaper colors. This local extension does not replace the app’s design system.
